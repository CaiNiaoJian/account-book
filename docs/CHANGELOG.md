# 更新记录

## 0.2.1 — 2026-10-04

- 修复概览仪表盘重算较多历史统计时的 500：系统临时目录不可用会导致 SQLite 临时查询文件创建失败。
- 每个数据库连接的临时查询表和索引改为内存存储；账本、WAL 和备份仍保持原来的磁盘持久化方式，无数据库迁移。
- 新增 Windows 故障回归：系统临时目录不存在时，旧方式复现 500，修复方式返回 200，并核对余额、收支和净值。
- 打包支持输出到独立程序目录，便于准备修复包而不替换正在运行的版本。

## 0.2.0 — 2026-10-03

- 统一归档账户与日期范围的净值口径；修复归档账户显示起始余额的问题。
- 日内净值正确计入余额校准与跨统计范围转账，排除作废流水。
- 九项全局读取独立恢复，保留已加载数据和填写中的内容；读取有超时，写入不自动重试。
- 新增记账请求去重，响应丢失后的同次重试返回原记录；阻止连续点击重复提交。
- 设置中新增完整手动/定期备份、导入、校验预览、独立恢复和打开恢复账本。
- 顶部增加跨页面待办和未读提醒，补齐信用卡账单/还款与债务到期提醒。
- 修复发薪日修改、实际薪酬款项填写和五险一金配置编辑。
- 统一 Python、网页、Windows 文件版本为 0.2.0，阶段标记为 P6。
- 便携下载包只包含程序文件，不包含本机账本、附件、配置或备份。

发布验证以 GitHub Windows verification 的实际运行结果为准，详见 Actions。
