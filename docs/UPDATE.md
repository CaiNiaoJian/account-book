# 更新与恢复

当前版本：0.2.0，主要功能覆盖 P0–P6。

## 更新便携版

1. 关闭旧版记账本。在「设置 → 备份与恢复」先完成一次完整备份，并将下载文件另存到其他磁盘。
2. 解压新版本，把 `AccountBook.exe` 和整个 `_internal` 文件夹替换到原程序目录。
3. 保留原来的 `data` 文件夹和 `portable.flag`，启动新版即可继续使用原账本。

不要删除旧 `data`，也不要把程序单独移动到另一个没有数据的目录后误以为账本被清空。
安装版默认保存在用户数据目录，可在设置中查看实际位置。

## 备份与恢复

完整 `.abk` 备份包含数据库（包括 WAL 中已提交的记录）、所有附件和配置。
不包含可重建的缓存、日志、浏览器会话、模型和插件程序。尚未保存的表单不属于已记录账本。
备份仅在本机生成，目前未加密，单份支持最多 2 GB；请妥善保管。

默认每 24 小时自动备份，程序需处于运行状态；到期后运行期间检查。可在设置中关闭或更改间隔。
自动备份不会自动删除旧文件，可下载或通过设置中的数据目录管理磁盘空间。
“定时任务”页面的通用 backup/report 任务仍标记未实现；完整自动备份由设置中的开关控制。

恢复流程：导入备份 → 验证并预览 → 恢复为独立账本 → 打开恢复的账本。
新账本位于当前数据目录的 `restored/book-*`，恢复不覆盖当前账本。
程序先校验清单、每个文件的哈希、数据库完整性、版本和附件引用；全部成功后才公布恢复目录。
失败时删除临时产物，当前账本保持原状。
可把完整恢复目录复制到别的磁盘，用 `AccountBook.exe --data-dir "恢复目录"` 打开。

## 金额口径

归档只隐藏账户，不删除或移除其资产。取消“计入净资产”仅影响净值，仍保留该账户的真实收支统计。
首页和账户总览按今天日终统计，日历、日内曲线、K 线和台账按选定日期统计。
未来日期流水仅在其所属日期及之后影响余额总览；账户的全时段查询接口保留原有语义。
人民币汇总与其他币种分开显示；没有汇率转换，不合计不同币种、不允许跨币种转账。
余额校准影响余额与净值，但不算收入或支出。
计入净资产范围内的转账抵消，跨范围转账会改变净值。

## 提醒

顶部待办入口跨页面可用。程序运行时检查信用卡账单日、负余额账户还款日及未结清债务到期日。
提醒不自动扣款或记账，必须核对实际账单。可以前往处理、确认已处理、稍后提醒或填写原因明确跳过。
程序关闭时不会推送提醒；重新打开会检查当前月份和已逾期债务。

## 启动环境

支持 Windows 10/11 x64，需要 Microsoft WebView2 Runtime。
代码尚未进行发行者签名，Windows SmartScreen 可能仍显示“发行者未知”。
GitHub Windows 验证会在独立环境构建并验证本地服务、原生窗口首次启动与重启、更新保留账本。
