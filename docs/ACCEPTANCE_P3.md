## 4. 本轮修掉的真实缺陷

| # | 问题 | 症状 | 根因与修复 |
|---|---|---|---|
| 1 | **金额被截断** | "18500" 解析成 185 元 | 千分位分支 `\d{1,3}(?:,\d{3})*` 里的 `*` 允许逗号组出现零次，于是把 "18500" 匹配成 "185"。改成 `+` 后纯数字串落到第二个分支 |
| 2 | 更新模板时校验崩溃 | `IN` 子句收到字符串 `"[]"` | 更新时 `merged` 取的是模型上的原始 JSON 文本。已在 `_validate` 内归一化（列表与 JSON 文本都接受） |
| 3 | 方向判断漏掉分类自带的方向 | 命中"午餐"却判定方向未定 | 分类自带 `kind`，读它不是"猜"。已补上（优先级低于金额符号与方向词） |
| 4 | K 线「均线」页签画的是回撤图 | 页签文字与图形不符 | `overlayOption` 只处理了 macd / rsi，`'ma'` 落到 else 分支。类型检查不会报，只能靠肉眼看出来 |
| 5 | 打点纵坐标给了 `null` | 事件图钉落到轴底部或不画 | 改为取所在蜡烛的最高价；找不到对应蜡烛的事件直接丢掉（宁可不标，不标错位置） |
| 6 | 截图脚本 `$error` 被当参数名 | 所有 HTTP 错误显示为空字符串 | `$Error` 是 PowerShell 自动变量，被遮蔽后 `ErrorDetails` 恒为 null |
| 7 | 截图脚本只查顶层分类 | 「房租」在「居住」下因此查不到 | `/api/categories` 返回的是**分类树**，必须递归展开 `children` |

## 6. 明确的已知局限

1. **快捷记账的模板栏与解析框只有类型检查 + 接口测试覆盖，没有截图**：
   它们位于对话框中，需要点击才会出现，而当前的无头截图流程不点击。
   解析逻辑本身有 30+ 条单元用例；
2. **组件级可拖拽仪表盘未做**：首页仍是分区级（图表区 / 列表区 / 运行状态）；
3. **P2 计划图表仍有四类未做**：分类构成堆叠面积、桑基图、气泡大额分布、
   预算仪表盘；日历格子波次点亮与卡片 3D 倾斜也未做；
4. K 线的「均线」副图只做了目视确认，没有与外部软件逐个数值比对；
5. 回撤基于日终值，日内低点不记录；
6. `docs/DATA_MODEL.md` 的 P1/P3 新表补充**未能写入**（写入时被文件锁拒绝），
   六张新表的说明目前只在本文与 [KLINE_METRICS.md](KLINE_METRICS.md) 里。
