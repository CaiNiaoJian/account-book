## P0 · 基座骨架（已交付）

### 桌面外壳
- ✅ pywebview + Edge WebView2 原生窗口；`ShellAdapter` 抽象，不可用时降级为浏览器外壳
- ✅ DWM 窗口美化：Windows 11 圆角、标题栏深色跟随**应用**主题（而非系统主题）
- ✅ Per-Monitor V2 DPI 感知（高分屏不发虚）
- ✅ 窗口几何记忆（关闭时保存一次，避免拖动过程中频繁写盘）
- ✅ 单实例锁（`msvcrt.locking`，进程崩溃后由系统自动释放，不留僵尸锁）

### 本地服务与安全
- ✅ 仅绑定 `127.0.0.1`，端口由系统随机分配
- ✅ 每次启动生成一次性会话令牌；Cookie / Bearer / `?token=` 三种携带方式
- ✅ 四道关卡：Host 校验（防 DNS rebinding）→ Origin 校验（防 CSRF）→ 令牌校验 → 路径穿越防护
- ✅ 安全响应头：CSP（`connect-src 'self'`）、`X-Frame-Options: DENY`、`Referrer-Policy`
- ✅ 静态资源匿名放行（仅限带扩展名的构建产物），彻底避免"Cookie 失效 → 白屏"

### 配置与数据
- ✅ **数据目录候选链**：逐个真实写入探测（`%LOCALAPPDATA%` → `%APPDATA%` → 文档目录 → 程序目录 → 临时目录），
  第一个可写者胜出；显式 `--data-dir` 则不做任何回退
- ✅ 每次选择都记录**来源与尝试记录**，并暴露到日志、`/api/system/info` 与概览页（降级时黄色提示 + 可展开明细）
- ✅ 双模式数据目录（安装版 `%LOCALAPPDATA%` / 便携版同级 `data/`），不可写时不再拒绝启动
- ✅ 偏好持久化（原子替换写入）+ 向前兼容（未知字段原样保留）
- ✅ 主题变更 → 后端 → 桌面外壳原生标题栏的完整链路
- ✅ 轮转日志 + 崩溃转储 + 全局/线程未捕获异常兜底
- ✅ `.gitignore` 严格隔离数据、密钥、备份、附件与构建产物（需求 14）

### 界面
- ✅ Apple 风格设计系统：CSS 变量令牌 + Tailwind 语义类，**界面无任何硬编码色值**
- ✅ 浅色 / 深色 / 跟随系统，带过渡动画与首帧无闪烁（模块加载即应用主题）
- ✅ 26 个模块的侧边栏导航，三分之一分组、可折叠、可即时过滤，未实现模块显示阶段徽标
- ✅ 自绘 SVG 图标集（30+ 图标，24 网格 / 1.6 描边，离线、无第三方素材）
- ✅ 中英双语 i18n，键集合在构建期校验（漏译会打包失败）
- ✅ 概览仪表盘：KPI 卡（诚实显示 `—` 与「待录入」）、示意趋势图（带 `DEMO` 水印）、真实运行状态卡
- ✅ 设置页（主题 / 减少动效 / 隐私模式 / 语言 / 数据目录 — 全部真实生效）
- ✅ 关于页（版本、构建类型、Python、路径、隐私声明、诊断命令）
- ✅ 通用占位页（模块说明 + 路线图时间轴 + 后续动作）
- ✅ 无障碍：`prefers-reduced-motion` + 应用内开关、`:focus-visible` 焦点环、`aria-label`

### 工程
- ✅ 72 项后端 pytest 用例（路径 / 安全 / HTTP 契约 / 偏好 / 静态托管 / 越权）
- ✅ ruff 检查 + 格式化；`# REQ-x` 需求追溯标记
- ✅ PyInstaller onedir 打包 + 冒烟测试脚本（`packaging/build_backend.ps1`）

## P2 · 资产卡片墙与可视化体系

- ⏳ `asset_snapshots` 周期末快照 + `daily_stats` 每日汇总缓存（增量重算）
- ⏳ **资产卡片墙**：银行卡 / 微信 / 支付宝 / 钱包 / 投资 / 负债分组，可拖拽排序、可上传私人卡面

- ⏳ **GitHub 式年度日历热力图**：6 类颜色主指标可切换 + 角标叠加 + 导出 PNG
- ⏳ 点击某日 → 当日详情面板：余额阶梯曲线、收支构成、流水清单、事件日志、变动归因
- ⏳ ECharts Apple 主题 + 12 类分析图表（旭日 / 桑基 / 矩形树 / 雷达 / 箱线 / 气泡 / 瀑布 / 堆叠面积…）
- ⏳ 可拖拽仪表盘小组件 + KPI 卡微图表（SVG Sparkline / 进度环）
- ⏳ 动效体系：页面转场、数字滚动、列表 FLIP、图表入场、骨架屏
